# Where Do We Eat public site

Use the original orange app icon, warm neutral canvas, system sans-serif, and sage supporting accents. Respect the user's preference for San Francisco; no custom serif or purchased font.

The site remains static HTML/CSS on GitHub Pages. Native links, details/summary, semantic tables, and a responsive guide table of contents provide interaction. No runtime framework, remote fonts, analytics, or decorative animation.

Real simulator screenshots illustrate Decide and the new introduction. Guide instructions follow beta build 15 and the in-app How It Works copy.

21st hero/sidebar search informed the structure. Retain the project's HTML primitives rather than introducing React components. CSS variables in style.css are design tokens; literal colors in their definitions are intentional.
